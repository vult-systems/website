<Heading level={2} size="4xl">Project Overview</Heading>

This character was created as part of Adam Skutt's Character Creation Course, using concept artwork by [Karl Kopinski](https://www.facebook.com/Art-of-Karl-Kopinski-382449358500042/) as the primary inspiration for the costume and overall visual direction. The project provided an opportunity to strengthen both my artistic and technical approach to character creation while learning from an artist whose work I have long admired.
